# pineridgelawn.example

Pine Ridge Lawn Care's site. Next.js (app router), deployed on a Node host.

- `npm run dev`
- Quote requests are mailed with Resend (`RESEND_API_KEY`, `QUOTE_TO`).
- Services and prices are in `data/services.ts`; business facts in `lib/site.ts`.
- Posts are Markdown in `content/blog/`.
